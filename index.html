Create a Point

Pulse Point, Particle Point, and Cloud Point each drop a point with that one effect ready to go. Highlighter drops a point rigged with the pulse+ring "important thing" combo. + Point (current layer) just points whatever layer you already have selected at a new point, for full manual control.

Points

A point is a standalone anchor, separate from the path. Any layer can target the path or one of these points, in the Effect section below.

All Layers

Every particle effect, shape, line, text item and Clip has its own layer. Selecting an FX layer opens Particles; selecting a shape layer opens the panel that owns that object. New tools can assign their own panel automatically.
